# 💼 Jargon Jumble: The Office Edition 📄

Welcome to **Jargon Jumble: The Office Edition**, a terminal-based word puzzle game built entirely in Python. Test your knowledge of iconic quotes, legendary pranks, and Dunder Mifflin lore!

Can you make it all the way to Regional Manager, or will you end up as Date Mike?

---

## 🚀 Features

- **Dynamic Word Bank:** Contains a curated list of nearly 20 classic quotes from *The Office*.
- **Randomized Gameplay:** Every session dynamically selects **8 unique rounds** using Python's `random` sampling, ensuring no two playthroughs are exactly the same.
- **Custom Feedback Scale:** Features a dynamic, show-themed scoring engine that ranks your performance from Angela's strict judgment up to the coveted "World's Best Boss" status.

---

## 🛠️ Tech Stack & Concepts Used

- **Language:** Python 3
- **Data Structures:** Tuples inside a List (`word_bank`) for secure, immutable question-and-answer pairs.
- **Modules:** `random` for non-repeating round generation.
- **Control Flow:** Complex conditional logic (`if/elif/else`) structures handling input validation and score scaling.

---

## 🎮 How to Play

1. Make sure you have Python installed on your machine.
2. Clone this repository:

   ```bash
   [git clone https://github.com](https://github.com/rysrn/python_projects.git)
   ```

3. Run the game from your terminal:

   ```bash
   python jargon_jumble.py
   ```

4. Read the sentence blank, guess the missing word, type it in, and press **Enter**!
